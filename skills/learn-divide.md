# Skill: learn-divide

Divide a learning topic into a structured outline.

## Guidance

- Choose the number of units from the topic's real complexity. A focused concept may need one or two units; a broader subject may need more.
- Include only concrete, teachable knowledgePoints. Do not add filler to reach a target count.
- Unit titles should be progressive (basics → practice → application / review).
- Prefer Chinese titles and knowledgePoints when the learner writes Chinese.
- Estimate time from the actual work required; short focused units are valid.
- `description` is optional short guidance for how to study the unit.

## Good knowledgePoints

- Specific concepts, skills, or checks (e.g. 「向量加法运算法则」「用点积判断正交」)
- Avoid filler like 「了解一下」「多练习」 without a concrete target

## Output

Only the JSON schema requested by OutlineAgent — no extra prose.
